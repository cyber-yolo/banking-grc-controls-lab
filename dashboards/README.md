# Dashboards

Two views, for two audiences.

## 1. Compliance dashboard (management body, second line)

`reports/compliance-dashboard.md`, generated by `tools/build_report.py` from an evaluation result. It shows control status per domain and per jurisdiction (EU, LU, CH), with the first failing assertion of each control. `reports/control-status.csv` holds the same data flat, for a spreadsheet or Power BI.

It is static on purpose: a management summary must point to one evidence run, with a hash manifest, not to a live view that changed since.

## 2. Operational workbook (first line), design

An Azure Monitor workbook on the lab workspace for the controls whose effectiveness is visible in logs. Phase 4, built in the portal and exported as JSON into `dashboards/workbook-controls.json` (same method as the playbooks: portal first, then code, IDs replaced by parameters).
