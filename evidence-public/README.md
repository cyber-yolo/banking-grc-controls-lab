# Public evidence

Redacted extracts from the lab campaign. Raw runs stay in the git-ignored `evidence/` folder and in the evidence archive; they are never committed. Method and redaction rules: [`docs/08-evidence-handling.md`](../docs/08-evidence-handling.md).

## Layout

`test-runs/<TC-ID>/<what>-<UTC timestamp>.<ext>` plus a short run sheet `<TC-ID>.md` (action time, evidence run ID, manifest hash of the relevant file, result, limits).
